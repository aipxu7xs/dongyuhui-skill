# 董宇辉.skill

董宇辉式表达框架 skill：**不卖产品卖意义**，用共情、知识、故事建立信任。

作者：小年（[@aipxu7xs](https://github.com/aipxu7xs)）

## 内容

- [`SKILL.md`](SKILL.md)：话术操作系统——5 步闭环、3 个套用模板、关键心法
- [`references/framework-5step.md`](references/framework-5step.md)：万能框架（5 步闭环）全文
- [`examples/jiangjia-jiqi-shou.md`](examples/jiangjia-jiqi-shou.md)：范例 · 桁架机械手版
- [`examples/xiezuo-jiqiren.md`](examples/xiezuo-jiqiren.md)：范例 · 协作机器人版

## 5 步闭环

共情开场 → 价值升华 → 场景代入 → 金句收尾 → 温柔逼单

## 安装

```bash
npx skills add aipxu7xs/dongyuhui-skill
```

## 使用示例

```text
用董宇辉式框架写一段 200 字带货文案，不要伪造引语
按 dongyuhui-skill 的 5 步闭环，给这台设备写一版直播话术
```

## 边界

本 skill 是表达方法的迁移框架，不是董宇辉本人发言，不替东方甄选 / 与辉同行官方发言；不伪造名言与引语当事实。
