# 董宇辉话术 · 万能框架（5 步闭环）

> 来源：小年 2026-11-26 提供的版本，补进本 skill 作为可直接套用的落地框架。
> 核心一句话：**不卖产品卖意义**——用共情、知识、故事建立信任。

## 一、核心万能公式（5 步闭环）

### 1. 共情开场（抓痛点）
用「也许你……但你没办法……」句式戳中情绪，拉近距离、留住人。
例：「也许你工作压力大想逃离城市，但责任在身无法远行。」

### 2. 价值升华（塑产品）
不说参数，转情绪 / 精神价值；加轻知识（材质典故、生活哲思）显质感。
例：卖保温杯不是卖容器，是忙时有人提醒你爱自己的温暖。

### 3. 场景代入（强画面）
描绘具体使用场景，让用户感知体验，而不是听功效说明。
例：压力时戴沉香手串，深呼吸仿佛置身森林，瞬间沉静。

### 4. 金句收尾（留记忆）
用诗意排比 / 人生感悟总结，强化认同。
例：「平凡日子的体面，藏在不将就的选择里。」

### 5. 温柔逼单（促转化）
强调「及时拥有」的意义，点到为止不硬催。
例：晚买没当下的欢喜，库存有限，别错过此刻的治愈。

节奏：共情 → 价值 → 场景 → 金句 → 逼单，循环递进。

## 二、3 个直接套用模板

**高客单通用：**
「也许你渴望 XX（理想状态），但现实中 XX（无奈）。它不用你妥协，XX（核心价值），让你在 XX 场景（使用时刻），感受 XX（情绪）。」

**知识型带货：**
「很多人找 XX（需求），其实难的是 XX（深层痛点）。它藏着 XX（知识 / 故事），不是消费，是给生活加 XX（价值）。」

**日常好物：**
「你是否总 XX（小遗憾）？别忽略自己，它 XX（卖点），提醒你 XX（关怀），忙也别忘善待自己。」

## 三、关键心法

- **状态**：语速放缓、真诚眼神，像朋友聊天。
- **内核**：真诚 + 知识储备，避免空洞煽情。
- **节奏**：共情 → 价值 → 场景 → 金句 → 逼单，循环递进。

按框架填充产品信息，就能快速输出「董式」高级话术。

## 四、机床版应用注记（2026-11-26 对照小年的桁架机械手范例）

小年的桁架机械手范例已无意识用上全 5 步：
共情 = 招工难、夜班没人、订单压着；升华 = 卖的不是设备，是守住客户信任的踏实感；
场景 = 旺季交付的关键时刻（此步最容易写概括，具体画面越细代入感越强）；
金句 = 「欲买桂花同载酒，终不是少年游」；温柔逼单 = 有了就别盲目买，没有就大方拿下。
